# js-labs

**Живое демо:** [anastasiatarasevich74.github.io/js-labs](https://anastasiatarasevich74.github.io/js-labs/)

18 учебных проектов на чистом JavaScript: калькуляторы, таймеры, счётчики, валидация, анимации. Без фреймворков и библиотек.

## Структура

### Базовое (`/basics`)
- [Генератор случайных чисел](basics/303.html) — работа с input и Math.random
- [Угадай число](basics/304.html) — игровая логика, счётчик попыток
- [Счётчик кликов](basics/305.html) — localStorage, сохранение состояния
- [Круг с анимациями](basics/306.html) — CSS-анимации, keyframes

### Текст (`/text`)
- [Печатная машинка](text/307.html) — анимация текста через setTimeout
- [Счётчик символов, слов, чисел](text/308.html) — регулярные выражения, обработка текста

### Время (`/time`)
- [Часы для Омска](time/310.html) — работа с датами и часовыми поясами
- [Секундомер](time/311.html) — миллисекунды, setInterval
- [Таймер обратного отсчёта](time/408.html) — AudioContext, звуковой сигнал

### Игры (`/games`)
- [Быки и коровы](games/313.html) — логика, история попыток
- [Крестики-нолики 5×5](games/404.html) — проверка победы по 4 направлениям

### Безопасность (`/security`)
- [PIN-код](security/314.html) — экранная клавиатура, валидация
- [Генератор паролей](security/402.html) — криптостойкая генерация
- [Проверка надёжности пароля](security/502.html) — strength meter, регулярки

### Калькуляторы (`/calculators`)
- [Простой калькулятор](calculators/407.html) — eval, обработка клавиатуры
- [Научный калькулятор](calculators/504.html) — sin/cos/tan, π, e, корень n-й степени

### Клавиатура (`/keyboard`)
- [Виртуальная русская клавиатура](keyboard/503.html) — смена раскладок, ввод символов

### Анимации (`/animations`)
- [Рождественская гирлянда](animations/315.html) — CSS-анимации, снежинки

## Технологии

- HTML5, CSS3 (flex, grid, анимации, градиенты)
- JavaScript (DOM, события, регулярные выражения, localStorage, AudioContext)
- Без фреймворков и библиотек

## Как запустить

Открыть любой `.html` в браузере или зайти на [живое демо](https://anastasiatarasevich74.github.io/js-labs/).
